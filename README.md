# AI Fintech Security Application

A personal project exploring the integration of cybersecurity principles, artificial intelligence concepts and cryptographic techniques within a financial application.

The goal of this project is to simulate a secure fintech environment where financial transactions can be monitored, validated and protected using modern security practices.

## Project Purpose

This application is designed to demonstrate how secure software development practices can be integrated into financial systems. The project focuses on protecting sensitive financial data and detecting potentially suspicious transaction behavior.

## Key Features

- Transaction recording and management
- Input validation for financial operations
- Basic anomaly detection logic for suspicious transactions
- Cryptographic protection of sensitive financial data
- Secure handling of user data
- Transaction history tracking

## Technologies

- C#
- .NET
- Cryptography libraries
- Basic AI / anomaly detection logic
- REST / Web application architecture

## Security Concepts Explored

- Secure software design
- Input validation
- Data encryption
- Secure handling of financial data
- Basic fraud / anomaly detection concepts
